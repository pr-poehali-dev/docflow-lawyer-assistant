# Запуск ЛЕГИС ПРО на своём сервере

Одна и та же инструкция подходит для Timeweb Cloud (Москва) и для вашего компьютера.

## Что нужно
- Linux-сервер или компьютер с Docker и Docker Compose
- Домен, направленный на сервер (для HTTPS). Без домена: `SITE_ADDRESS=localhost`
- Почтовый ящик с SMTP для отправки кодов входа

## Запуск
1. Скачайте код: Скачать → Скачать код (или подключите GitHub).
2. `cp .env.example .env` и заполните значения (пароли, секрет, SMTP, домен).
3. `docker compose up -d --build`
4. Откройте сайт. Первый вошедший создаёт администратора.

## Безопасность
- База данных не имеет открытых портов, доступна только API внутри сети Docker.
- Снаружи открыты только 80 и 443. Сертификат HTTPS выпускается автоматически.
- Вход: пароль и код из письма. Журнал входов и журнал действий хранятся в базе.
- Документы выдаются по временным ссылкам (10 минут) только вошедшим сотрудникам.
- На сервере откройте только порты 22 (SSH по ключу), 80, 443.

## Резервные копии
Каждую ночь (час `BACKUP_HOUR`) в папку `BACKUP_DIR` складывается зашифрованный архив: база и файлы. Хранится `BACKUP_KEEP_DAYS` дней. Периодически копируйте папку вне сервера.
Восстановление: `BACKUP_PASSPHRASE=... POSTGRES_USER=... POSTGRES_DB=... ./deploy/restore.sh backups/legis_ДАТА.tar.enc`

## Перенос данных с платформы (только после вашего подтверждения)
1. Выгрузка: `SOURCE_DATABASE_URL=... SOURCE_SCHEMA=... python3 deploy/export_data.py export`
2. Загрузка на новый сервер: `DATABASE_URL=postgresql://... python3 deploy/import_data.py export`
3. Файлы документов (если появятся): скопировать в том `filesdata`, ссылки в базе обновятся при повторной генерации.

## Переезд с Timeweb на свой компьютер
Скопируйте проект и `.env`, запустите `docker compose up -d --build`, восстановите последнюю копию командой выше и переключите домен на новый адрес.
